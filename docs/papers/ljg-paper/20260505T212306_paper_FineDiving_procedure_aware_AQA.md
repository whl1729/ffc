# 问题

跳水打分，AI 给出一个数字，但说不清楚为什么。

"向后 3.5 周团身"和"向后 2.5 周团身"，视频看起来差不多，但分数差很多。模型如果只是把整段视频压成一个特征向量再回归，它根本不知道"这个动作的起跳阶段做得好，但入水时水花太大"——它只知道"这段视频对应 83 分"。

问题的根子在于：现有 AQA 数据集没有细粒度标注。只有总分，没有"起跳/飞行/入水"各阶段的标注，模型就没法学会分阶段评估。FineDiving 就是为了填这个坑。

# 翻译

## 锚点：一个把跳水动作拆成乐谱的裁判

想象一个裁判，他不只给出最终分数，还把整个跳水动作拆成一个"乐谱"：第一步是起跳（Reverse），第二步是飞行（3.5 周团身），第三步是入水（Entry）。他对每一步单独评分，最后加权得到总分。

FineDiving 就是把这个"乐谱"标注出来，然后训练模型按乐谱打分。

## 数据集：两层语义 + 两层时序

FineDiving 从奥运会、世界杯、世锦赛收集了 3000 段跳水视频，覆盖 52 种动作类型、29 种子动作类型、23 种难度等级。

标注有两个维度：

**语义结构**（这个动作是什么）：
- 动作类型（粗粒度）：比如"5255B"= 向前 2.5 周转体 2.5 周屈体
- 子动作类型（细粒度）：把动作拆成"起跳方向 + 空中姿势 + 转体圈数 + 入水"

**时序结构**（每个阶段在哪里）：
- 动作级别：整个跳水动作的起止帧
- 步骤级别：每个子动作阶段的起始帧

这是 AQA 领域第一个同时有细粒度语义标注和时序标注的数据集。

## 方法：TSA（时序分段注意力）

TSA 的核心思路是：把查询视频和参考视频都拆成对应的步骤，然后逐步比较。

```
查询视频 (X)          参考视频 (Z)
    |                     |
[I3D 提特征]          [I3D 提特征]
    |                     |
[分段模块 S]          [分段模块 S]
    |                     |
步骤1, 步骤2, 步骤3   步骤1, 步骤2, 步骤3
    |                     |
    +-----[跨注意力]-------+
    |  (查询步骤 vs 参考步骤)
    |
[细粒度对比回归]
    |
预测分数差 + 参考分数 = 最终分数
```

关键在"跨注意力"这一步：查询视频的"起跳"步骤和参考视频的"起跳"步骤做注意力，模型学会"在参考视频里找和查询步骤对应的区域"。这样比较的是同一阶段的质量差异，而不是整体视频的模糊差异。

**效果**

在 FineDiving 上，TSA（使用动作类型选参考视频）SRCC 达到 0.9203，比 CoRe（0.9061）高 1.4%，比 USDL（0.8913）高 2.9%。

# 核心概念

## 程序感知对比回归（Procedure-aware Contrastive Regression）

**一句话**：不比较整段视频，而是逐步骤比较，每个步骤的质量差异加权得到总分差。

**变形过程**：视频级对比回归（整段视频 vs 整段视频）→ 先把两段视频都拆成对应步骤 → 步骤级对比（起跳 vs 起跳，飞行 vs 飞行，入水 vs 入水）→ 每步的分数差平均 → 加上参考分数得到最终分数。

**为什么重要**：视频级对比回归是"整体感觉差多少"，步骤级对比回归是"哪个阶段差多少"。后者不只更准，还更可解释——可以告诉运动员"你的入水比参考差了 2 分，但起跳和飞行差不多"。

## 分段模块（Procedure Segmentation）

**一句话**：自动找到视频里每个子动作阶段的边界帧。

**类比**：就像给一首歌自动标注"前奏/主歌/副歌/尾奏"的时间点。分段模块预测每个"步骤切换"发生在哪一帧，把连续视频切成有语义的片段。

**为什么重要**：没有分段，就没法做步骤级比较。分段的准确性直接决定后续对比回归的质量。实验显示，加入分段模块后 SRCC 从 0.8576 提升到 0.8793，再加上跨注意力后进一步提升到 0.9203。

# 洞见

**可解释性不是通过可视化热力图实现的，而是通过结构化标注实现的**——当模型被迫按"起跳/飞行/入水"三个阶段分别打分时，它的推理过程自然变得可追溯。这个洞见的意义在于：要让 AQA 可解释，不是在模型上加解释模块，而是在数据上加结构化标注。

# 博导审稿

数据集贡献是这篇论文最扎实的部分。3000 个样本、52 种动作类型、两层语义 + 两层时序标注——这个标注体系比之前所有 AQA 数据集都精细，后来成了细粒度 AQA 的标准 benchmark，被大量后续工作引用。

方法上，TSA 的思路清晰：分段 → 跨注意力 → 细粒度对比回归，每一步都有明确的动机。消融实验也做得扎实，验证了每个组件的贡献。

有一个值得追问的地方：分段模块假设步骤数 L 是已知的（论文里固定为 2，即 3 个步骤）。但实际上不同动作类型的步骤数不同（3-5 步），论文选择了最简化的设定。这个假设在实际应用里是个限制——如果不知道动作类型，就不知道该分几步。

另外，多参考视频投票（M=10）在推理时需要 10 次前向传播，计算成本是单参考的 10 倍。论文没有讨论这个效率问题。

**判决：strong accept**。数据集贡献大，方法有效，实验扎实，是细粒度 AQA 方向的奠基性工作。

# 启发

**迁移**：FineDiving 的两层标注框架（语义结构 + 时序结构）可以直接用在任何有"标准程序"的运动上——体操（起跳/空中/落地）、跳高（助跑/起跳/过杆/落地）、武术套路（每个招式的起止）。如果你在设计 AQA 数据集，先问：这个运动能不能拆成有语义的子阶段？能的话，把子阶段边界标注出来，比只标总分有用得多。

**混搭**：TSA 的步骤级对比 + EgoExo-Fitness 的技术要点核查可以组合：用 TSA 找到"哪个阶段质量差"，再用技术要点核查找到"这个阶段具体哪个要点没满足"。两层诊断比任何一层单独都更精准。

**反转**：TSA 假设"参考视频的步骤数和查询视频一样"。但实际比赛里，高手和初学者做的可能是不同难度的动作（步骤数不同）。反过来想：能不能用 TSA 的框架做"跨难度比较"——把初学者的 3 步动作和高手的 5 步动作对齐，找出"在相同阶段里，高手多做了什么"？这对教学比同难度比较更有价值。
