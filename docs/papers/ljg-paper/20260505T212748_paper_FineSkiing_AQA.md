# 问题

空中技巧滑雪，裁判怎么打分？

他们把整个动作分成三个阶段：起跳腾空（air）、空中姿态（form）、落地（landing），每个阶段单独扣分，最后加总。"膝盖弯曲"在腾空阶段扣一档，在姿态阶段扣另一档；"立即摔倒"在落地阶段是最重的扣分项。

现有 AQA 方法不知道这些。它们把视频切成固定长度的 32 帧片段，提特征，回归分数——完全不知道"现在是腾空阶段还是落地阶段"，也不知道"这个阶段该看什么"。结果是：模型能给出一个数字，但说不清楚为什么。

FineSkiing 就是来填这个坑的：第一个有阶段分数和扣分项标注的 AQA 数据集，配套方法 JudgeMind 模拟裁判的打分思路。

# 翻译

## 锚点：一个按评分手册打分的裁判

想象一个 FIS 认证的裁判，他手里有一本评分手册，上面列了 40 种扣分项，分属三个阶段。他看完一个动作，不是给出一个整体印象分，而是逐阶段核查：腾空时腿有没有分开？姿态阶段滑板有没有叉开？落地时有没有摔倒？每个扣分项打上去，最后加总。

JudgeMind 就是把这个裁判的工作流程编码成神经网络。

## 数据集：FineSkiing

从 2014、2018、2022 三届冬奥会收集了 550 段空中技巧视频（440 训练 / 110 测试），每段平均 7.7 秒。标注比任何已有 AQA 数据集都细：

```
FineSkiing 标注层级
├── 动作类型（跳跃代码，如 bLTF = 后空翻-侧躺-团身-转体）
├── 难度系数（预定义）
├── 总分（5 名裁判去掉最高最低后平均）
├── 子动作边界（每个翻转/转体的起止帧）
├── 阶段边界（air / form / landing 的起止帧）  ← 首次
├── 阶段分数（三个阶段各自的子分）           ← 首次
└── 扣分项（40 种，含时间戳和严重程度）       ← 首次
```

和 FineDiving 比：FineDiving 有子动作边界，但没有阶段分数和扣分项。FineSkiing 是第一个把"为什么扣分"标注出来的 AQA 数据集。

## 方法：JudgeMind

```
输入视频
    |
[时序分段模块（CLIP ViT）]
    |
air 段 / form 段 / landing 段
    |
[阶段感知特征提取]
    ├── 非核心帧（air/landing）：前景特征 + 全局特征
    │   （运动员位置 + 与雪道的空间关系）
    └── 核心帧（form）：前景特征 + 动作代码先验
        （运动员姿态 + "这个动作应该是什么样"）
    |
[上下文融合编码器]
    |
[知识感知等级解码器（K-GAD）]
    ├── 可学习等级原型（K 个）
    ├── 扣分知识（BERT 编码的扣分项文本）
    └── 交叉注意力（原型 × 视频特征）
    |
[Likert 评分模块]
    |
各阶段分数 → 求和 → 最终分数
```

关键设计有两个：

**阶段感知特征提取**：不同阶段看不同的东西。腾空和落地阶段，运动员在画面里很小，关键是他和雪道的空间关系，所以同时提前景和全局特征。姿态阶段，运动员占满画面，关键是动作细节，所以只提前景特征，同时注入动作代码先验（"这个动作应该做 bLTF"）。

**知识感知等级解码器（K-GAD）**：把扣分项文本（"膝盖弯曲"、"早期准备"）用 BERT 编码，和可学习的等级原型做交叉注意力。模型不只是从视频里学"这个动作是几分"，还学"这个阶段的扣分项是什么，视频里有没有出现"。

**效果**：在 FineSkiing 上 SRCC 0.927，比第二名 CoFInAl（0.883）高 4.4%。在 FineDiving 上 SRCC 0.924，也是 SOTA。

消融实验显示每个组件都有贡献：去掉时序分段 SRCC 从 0.927 降到 0.908（-0.019），去掉前景提取降到 0.913（-0.014），去掉扣分知识降到 0.922（-0.005）。

# 核心概念

## 知识感知等级解码器（K-GAD）

**一句话**：把扣分规则文本编码成先验知识，让模型在打分时"知道该看什么"。

**变形过程**：纯视觉回归（看视频猜分数）→ 引入可学习等级原型（K 个原型代表 K 个质量等级）→ 把扣分项文本编码后乘进原型（原型变成"知道扣分规则的等级原型"）→ 原型和视频特征做交叉注意力（从视频里找扣分项的证据）→ 输出等级感知特征 → Likert 评分。

**为什么重要**：没有 K-GAD，模型只能从数据里隐式学"什么样的视频对应什么分数"。有了 K-GAD，模型被显式告知"这个阶段可能出现哪些扣分项"，相当于给模型一本评分手册，让它按手册核查而不是凭感觉打分。

## 阶段感知特征提取

**一句话**：不同阶段用不同的特征提取策略，因为不同阶段"该看什么"不一样。

**类比**：就像一个摄影师，拍腾空时用广角镜头（看运动员和雪道的整体关系），拍姿态时换长焦镜头（看运动员的动作细节）。同一个场景，不同时刻用不同的镜头。

**为什么重要**：空中技巧视频有频繁的摄像机切换（近景/远景交替），固定的特征提取策略在视角切换时会失效。阶段感知提取把"该用什么镜头"这个决策显式建模，而不是让模型自己猜。

# 洞见

**扣分项是比分数更有价值的监督信号**——分数是扣分项的加权和，但反过来从分数推扣分项是欠定问题。FineSkiing 直接标注扣分项，让模型可以学"为什么扣分"而不只是"扣多少分"。这个逻辑意味着：AQA 数据集的标注应该从"总分"升级到"扣分项"，这比换更强的骨干网络更有价值。

# 博导审稿

数据集贡献扎实。550 个样本不算大，但扣分项标注是第一个，而且经过 FIS 认证裁判验证，质量可信。40 种扣分项、三个阶段的子分——这个标注体系比 FineDiving 更细，后续工作很难绕开。

方法上，JudgeMind 的思路清晰：分段 → 阶段感知提取 → 扣分知识注入 → Likert 评分，每一步都有明确动机。消融实验也做得扎实。

有一个值得追问的地方：550 个样本，40 种扣分项，平均每种扣分项只有十几个样本。K-GAD 能从这么少的样本里学到可靠的扣分项识别吗？论文没有分析每种扣分项的识别准确率，只报告了整体 SRCC。如果某些罕见扣分项（比如"立即摔倒"）样本太少，K-GAD 对这些项的学习可能是无效的。

另外，论文在 FineDiving 上测试时，因为没有阶段分数标注，只能用总分训练，结果 SRCC 0.924 仍然是 SOTA——这说明 JudgeMind 的架构本身就有优势，不完全依赖细粒度标注。但论文没有深入分析"细粒度标注到底贡献了多少"。

**判决：weak accept**。数据集贡献有价值，方法有效，但样本量小、扣分项分析不足，泛化性存疑。

# 启发

**迁移**：FineSkiing 的"扣分项文本 → BERT 编码 → 注入模型"框架可以直接用在任何有明文评分规则的运动上——体操（FIG 评分手册）、跳水（FINA 规则）、花样滑冰（GOE 扣分项）。如果你在做 AQA，先问：这个运动的评分规则能不能枚举成文本？能的话，把规则文本注入模型，比只用视频特征更可靠。

**混搭**：JudgeMind 的扣分知识注入 + FLEX 的 FKG 结构可以组合：用 FKG 定义扣分项的层级关系（动作 → 阶段 → 错误类型），再用 K-GAD 把这个层级结构注入模型。两者结合比任何一个单独都更完整——FKG 提供结构，K-GAD 提供注入机制。

**反转**：JudgeMind 假设"阶段边界是可以自动分割的"。但消融实验显示去掉时序分段 SRCC 只降了 0.019——分段的贡献比预期小。反过来想：如果分段不准确（比如摄像机切换导致分段错误），K-GAD 的扣分知识注入会不会反而有害？论文没有分析分段错误对最终性能的影响，这是一个潜在的脆弱点。
