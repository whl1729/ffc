# 问题

AQA 的综述已经有好几篇了，为什么还要再写一篇？

因为已有综述有两个共同的盲点：一是以视觉为中心，忽略了多模态方法（骨架、音频、文本）的快速崛起；二是只按应用领域分类（体育/手术/康复），没有从方法论角度分析不同学习范式（监督/对比/半监督/持续学习）的适用场景。这篇综述从这两个维度重新组织了 AQA 领域的 200+ 篇论文，同时给出了应用导向的分析——不同场景对模型的要求不同，这个差异决定了方法选择。

# 翻译

## 锚点：一个按两个维度整理书架的图书管理员

想象一个图书管理员，他不只按"体育/医疗/技能"分类，还按"这本书用什么方法解决问题"分类。同一本书可能同时出现在"体育"和"对比学习"两个索引里。这样读者既能找到"体育 AQA 有哪些方法"，也能找到"对比学习在哪些场景下最有效"。

这篇综述就是这样的双维度索引。

## 两个分类维度

**按应用分**：体育（竞技评分、训练反馈）、医疗（康复监测、异常动作检测）、技能评估（日常技能、手术技能）。

**按方法分**：

```
AQA 方法论演化（2014-2025）
├── 传统方法（手工特征 + SVR）
├── 通用深度学习
│   ├── 视频级回归（C3D/I3D + 全连接）
│   ├── 注意力机制（Transformer）
│   ├── 时序分段建模（把动作拆成子阶段）
│   ├── 交互感知建模（关节关系、主次角色）
│   └── 不确定性建模（分数分布而非点估计）
├── 对比学习（和参考视频比较打分）
├── 半监督学习（少量标注 + 大量无标注）
├── 域迁移（跨数据集、跨场景）
├── 持续学习（不遗忘旧知识地学新任务）
├── 因果推断（去除背景干扰，找真正的因果关系）
└── 多模态融合（RGB + 骨架/音频/文本）
```

## 关键数据点

- 2024 年发表 35 篇 AQA 论文，2025 年已有 32 篇，增长趋势持续
- 体育数据集最多（15 个），医疗和技能评估数据集稀缺
- 最大数据集 Fitness-AQA 有 21284 个样本，但大多数数据集只有几百到几千个
- 对比学习方法（CoRe、T2CR、FineParser）在 MTL-AQA 上 SRCC 达到 0.96+
- 半监督方法（TRS）用 40% 标注数据就能超过部分全监督方法

## 应用场景决定方法选择

这篇综述最有价值的洞察是：**不同应用场景对模型的要求根本不同**，不能用同一套方法套所有场景。

```
场景          核心需求              适合的方法
竞技评分      准确性 + 与裁判一致   全局/分段时序建模
训练反馈      可解释性 + 细粒度     神经符号 + 分段解析
医疗康复      鲁棒性 + 可解释       轻量骨架 + 规则约束
技能评估      泛化性 + 数据效率     迁移学习 + 半监督
```

## 四个主要挑战

1. **摄像机噪声**：运动模糊、遮挡、视角变化，在高速运动（跳水、体操）中尤为严重
2. **标注成本**：需要专家标注，众包不可行，导致数据集规模受限
3. **多模态数据稀缺**：骨架数据在高速运动中误差大，文本数据需要专门收集
4. **隐私限制**：医疗数据受伦理约束，大量数据集不公开

# 核心概念

## 对比回归（Contrastive Regression）

**一句话**：不直接预测绝对分数，而是预测"这个动作比参考动作好多少"。

**变形过程**：直接回归（输入一个视频，输出一个分数）→ 对比回归（输入两个视频，输出分数差）→ 最终分数 = 参考分数 + 预测的分数差。

**为什么重要**：裁判打分本来就是比较性的——"这个跳水比那个好"比"这个跳水是 83 分"更自然。对比回归把这个比较过程显式建模，在 MTL-AQA 上 SRCC 从 0.93 提升到 0.96。

## 因果感知 AQA

**一句话**：用因果图区分"真正影响分数的动作特征"和"恰好和分数相关的背景噪声"。

**类比**：就像区分"因为腿没并拢所以扣分"（因果关系）和"因为穿蓝色泳衣所以分数高"（虚假相关）。普通深度学习模型可能学到后者，因果推断强制模型只学前者。

**为什么重要**：AQA 数据集小，模型容易学到虚假相关（特定摄像机角度、特定背景）。因果推断是提升泛化性的根本手段，而不只是换更大的模型。

## 持续学习 AQA

**一句话**：模型学了新运动项目之后，不能忘记旧项目的打分能力。

**变形过程**：静态训练（一次性学所有数据）→ 持续学习（顺序学习新任务）→ 灾难性遗忘（学新忘旧）→ MAGR（对齐历史特征和当前特征流形，防止遗忘）。

**为什么重要**：实际部署的 AQA 系统需要随着新赛季、新规则不断更新，而不是每次都从头训练。这是从实验室到实际应用的关键一步。

# 洞见

**AQA 的方法选择不应该由"哪个方法在排行榜上最高"决定，而应该由"这个应用场景最需要什么"决定**——竞技评分需要准确性，训练反馈需要可解释性，医疗康复需要鲁棒性，技能评估需要泛化性。这四个需求对应四类不同的方法，没有一个方法能同时满足所有需求。

# 博导审稿

这篇综述的最大贡献是应用导向的分析框架——明确指出不同场景对模型的要求不同，这是之前综述没有做到的。双维度分类（应用 + 方法论）也比单维度分类更有用，读者可以从两个方向检索。

不足之处：第一，和同年的 Yin et al.（A Decade of AQA）以及 Zhou et al.（Comprehensive Survey）有大量重叠，差异化不够明显。第二，"因果推断"和"持续学习"部分覆盖的论文数量少，分析深度不足。第三，综述声称覆盖到 2025 年，但很多 2024-2025 年的新方法只有一两句话的描述。

**判决：weak accept**。应用导向的分析框架有价值，但和已有综述的差异化不够，深度不均匀。作为入门参考有用，但不如 Yin et al. 全面。

# 启发

**迁移**：这篇综述的"场景-需求-方法"对应表可以直接用作选方法的决策树——先问"我的应用场景最需要什么"，再根据需求选方法，而不是直接去找 SRCC 最高的方法。

**混搭**：综述指出"因果推断 + 规则约束"是提升可解释性的方向，同时"半监督学习"是解决数据稀缺的方向。可以把两者结合：用因果图定义"哪些特征真正影响分数"，再用这个因果结构作为半监督学习的归纳偏置，让模型在少量标注数据下也能学到正确的因果关系。

**反转**：综述里所有方法都假设"视频是输入"。但在医疗康复场景里，患者在家用手机拍的视频质量很差——光线不稳定、角度随意、背景杂乱。反过来想：与其在低质量视频上堆更复杂的模型，不如先设计一个"视频质量评估"前置步骤，只对质量足够好的视频做 AQA，对质量差的视频提示用户重拍。这比强行处理低质量输入更实用。
