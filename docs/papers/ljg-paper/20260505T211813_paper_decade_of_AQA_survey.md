# 问题

AQA 做了十年，论文超过 200 篇，但这个领域的全貌没人画过。

不是没有综述，而是已有综述太旧、太窄——只覆盖体育，不覆盖手术和康复；只列方法，不分析趋势；只描述现状，不指出下一步。这篇论文用 PRISMA 框架系统筛选了 200+ 篇论文，画出这十年的完整地图：从 2014 年第一篇到 2024 年底，方法怎么演化，数据集怎么增长，还有哪些问题没解决。

# 翻译

## 锚点：一张从 2014 到 2024 的演化时间线

想象一张时间轴，左边是 2014 年的 L-SVR（用姿态特征 + 支持向量回归打分），右边是 2024 年的神经符号系统（用规则 + 神经网络生成可解释报告）。中间十年，方法从粗到细，从单模态到多模态，从黑盒到可解释，从单任务到持续学习。

这篇综述就是这张时间轴的注解。

## 地图：7 个研究趋势

他们把 200+ 篇论文归纳成 7 个主要趋势：

```
AQA 研究趋势（2014-2024）
├── 1. 基础研究（2014-2019）
│   -- C3D+LSTM，奠定特征提取+回归的基本范式
├── 2. 细粒度 AQA（主流，占比最大）
│   ├── 分段感知：把动作拆成子阶段分别建模
│   ├── 以运动员为中心：先检测人体，去掉背景干扰
│   ├── 客观评估：不确定性建模 + 对比回归，减少主观偏差
│   └── 非对称关系：双人动作里主次角色的不同权重
├── 3. 多任务 & 多模态 AQA
│   -- 文本、骨架、音频辅助打分
├── 4. 泛化性 AQA
│   -- 跨运动项目、跨数据集的迁移
├── 5. 持续学习 AQA
│   -- 模型随时间更新而不遗忘旧知识
├── 6. 可解释 AQA
│   -- 不只给分数，还给"为什么"
└── 7. 自监督 AQA
    -- 用无标注数据减少对专家标注的依赖
```

## 数据集全景：26 个，9 个领域

从 2014 年的 MIT-Dive（159 个跳水样本）到 2024 年的 EgoExo-Fitness（6131 个健身样本），26 个公开数据集覆盖手术、康复、日常活动、音乐、健身、工业制造、舞蹈、AI 生成视频、体育 9 个领域。

体育占比最大（15 个数据集），但最有意思的新方向是 GAIA——第一个用 AI 生成视频构建的 AQA 数据集，用来评估文生视频模型的动作质量。

## 方法演化的关键节点

**2014**：Pirsiavash 等人用姿态特征 + SVR，SRCC 0.41，开创 AQA 领域。

**2017**：Parmar & Morris 引入 C3D 深度特征，SRCC 跳到 0.79，同时建了 AQA-7 数据集。

**2020**：USDL 引入不确定性建模，把分数标签软化成高斯分布，SRCC 0.93。

**2021**：CoRe 引入对比回归，和参考视频比较后打分，SRCC 0.93。

**2022**：FineDiving 数据集 + TSA 模块，细粒度分段建模，SRCC 0.96。

**2024**：NS-AQA 用神经符号系统生成可解释报告，同时达到 SOTA 性能。

## 三个未解决的核心挑战

**数据**：最大的 AQA 数据集只有 2 万样本，而动作识别数据集有几百万。专家标注贵，众包不可行。

**可解释性**：大多数方法是黑盒。运动员需要"你的腿没并拢"，不是"你的分数是 83"。

**鲁棒性**：多模态方法假设所有模态都在，但实际场景里摄像头会坏、音频会缺失。

# 核心概念

## 细粒度 AQA 的四个子方向

**一句话**：把"整体打分"拆成"分段打分 + 关注运动员 + 减少主观偏差 + 处理多人关系"四个维度。

**变形过程**：早期方法把整段视频平均特征打分（粗）→ 分段感知（把起跳/飞行/入水分开建模）→ 以运动员为中心（先检测人体，去背景）→ 不确定性建模（分数是分布，不是点）→ 对比回归（和参考视频比较）。每一步都在缩小"模型看到的"和"裁判真正在看的"之间的差距。

**为什么重要**：细粒度是这十年 AQA 进步最大的方向，从 SRCC 0.41 到 0.96，大部分提升来自这里。

## 持续学习 AQA

**一句话**：模型学了新运动项目之后，不能忘记旧项目的打分能力。

**类比**：就像一个裁判学会了评判新项目，但不能因此忘记怎么评判跳水。深度学习模型的默认行为是"学新忘旧"（灾难性遗忘），持续学习就是解决这个问题。

**为什么重要**：实际应用里，AQA 系统需要随着新赛季、新规则、新运动项目不断更新，而不是每次都从头训练。

## 神经符号 AQA（NS-AQA）

**一句话**：用神经网络提取视觉符号（"入水角度"、"水花大小"），再用规则计算分数，整个过程可追溯。

**变形过程**：黑盒神经网络（输入视频，输出分数，中间不可见）→ 神经网络只做视觉解析（提取可解释的符号）→ 规则引擎用这些符号按照比赛规则计算分数 → 每一分都有来源。

**为什么重要**：这是目前唯一能同时达到 SOTA 性能和完全可解释的方法。2024 年在 FineDiving 上达到 0.961 SRCC，同时能生成详细的文字报告。

# 洞见

**AQA 的终极目标从来不是更高的 SRCC，而是让运动员知道"哪里做错了"**——十年来大多数论文在追求排行榜上的数字，但真正有用的系统是能说出"你的入水角度偏了 5 度"的那种。神经符号方法在 2024 年同时实现了高性能和可解释性，这才是这个领域真正的里程碑。

# 博导审稿

这是目前最全面的 AQA 综述，没有之一。200+ 篇论文、PRISMA 框架、26 个数据集、7 个研究趋势——覆盖面和系统性都超过之前所有综述。

特别有价值的是两点：一是把 AQA 扩展到体育之外（手术、康复、工业制造、AI 生成视频），让读者看到这个技术的真实应用边界；二是对"金标准动作"这个问题的提问——现有对比回归方法都需要一个参考视频，但什么才是"完美的参考"？这个问题没有答案，但提出来本身就有价值。

不足之处：7 个研究趋势的划分有些重叠，"细粒度"和"多模态"之间的边界不清晰。另外，对每个方法的分析深度不均匀，有些方法只有一两句话，读者很难判断该不该深入读原文。

**判决：strong accept**。覆盖面最广、系统性最强的 AQA 综述，是这个领域的必读参考。

# 启发

**迁移**：这篇综述的 7 个研究趋势可以直接用作 AQA 论文的定位框架——读一篇新论文，先问它属于哪个趋势、在哪个数据集上测、用什么骨干网络。四个问题问完，这篇论文在地图上的位置就清楚了。

**混搭**：综述指出"自监督 AQA 能减少对专家标注的依赖"，同时"神经符号方法能生成可解释报告"。可以把两者结合：用自监督方法从大量无标注视频里学视觉表示，再用神经符号方法把这些表示转化成可解释的评分报告。这样既解决了数据稀缺问题，又保持了可解释性。

**反转**：综述里所有方法都假设"分数是真值"。但裁判打分有偏差——民族偏见、最近效应（最后几秒影响最大）、难度偏见。反过来想：与其用有偏差的分数训练模型，不如先建一个"去偏差"的分数标注流程，再训练模型。这比在有偏数据上堆更复杂的模型更根本。
