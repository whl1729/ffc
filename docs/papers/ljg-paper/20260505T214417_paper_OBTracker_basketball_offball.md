# 问题

篮球比赛里，拿球的人只有一个，不拿球的四个人在干什么？

传统篮球统计只看得分和助攻——都是围着球转的数字。但一个球员跑到空位、甩开防守、创造投篮机会，这些对进攻有贡献的无球跑动，数据表上看不到。教练想分析"哪种无球跑动最有效""哪个球员最会跑位"，只能靠眼睛看录像，一场一场标注，累死人。

OBTracker 就是来解决这个问题的：第一个专门分析篮球无球跑动的可视化系统，用可解释的模型量化无球跑动的进攻贡献，用三层视图（球队→球员→动作）支持多层次分析。

# 翻译

## 锚点：一个会打分的无球跑动裁判

想象一个裁判，他不看球在哪儿，专门盯着那四个没拿球的人。他能看出：这个人跑到左翼三分线外，甩开了防守，如果现在传球给他，他有 70% 概率接到球，接到后有 0.8 分的期望得分。他把每次无球跑动都打个分，告诉教练"这次跑位值 0.5 分"。

OBTracker 就是把这个裁判的判断过程数字化，再用可视化让教练能快速找到"哪种跑位最常用""哪个球员跑得最好""为什么这次跑位成功了"。

## 三层分析：从球队到动作

OBTracker 用三个视图支持从粗到细的分析：

```
第一层：球队总览（Summary View）
├── 球队列表：每队的无球跑动数量 + 平均贡献
└── 跑动总览：每种跑动类型的频率 + 效果 + 比赛情境
    -- 用圆形字形图（glyph）展示跑动路径
    -- 两个直方图显示"比分差距"和"剩余时间"分布

第二层：球员表现（Player View）
├── 球员组合列表（切入者 + 掩护者 + 持球者）
└── 三个指标：频率、投篮期望、传球概率
    -- 可调权重排序，找最佳组合

第三层：动作解释（Explanation View）
├── 选择面板：定位具体的无球跑动
└── 跑动流程：用 Voronoi 图展示每帧的攻防态势
    -- 并排对比两个跑动过程
    -- 流图显示投篮期望和传球概率的变化趋势
```

## 核心：可解释的评分模型

OBTracker 的评分模型把"无球跑动的贡献"拆成两步：

**第一步：投篮期望**（假设球员接到球，他能得多少分？）

用三个矩阵相乘：
- 支配区域矩阵：用高斯分布算球员对周围区域的控制力
- 防守矩阵：用 Voronoi 图标记防守者控制的区域（这些区域值为 0）
- 投篮能力矩阵：用球员的历史投篮数据（每个区域的投篮频率 × 平均得分）

三个矩阵逐元素相乘，求和，得到投篮期望。

**第二步：传球概率**（持球者能把球传给他的概率？）

用线性回归模型，输入四个特征：
- 传球距离
- 传球路径附近的防守者数量
- 防守者到传球路径的平均距离和最小距离

模型在 32297 个传球时刻上训练，Top-1 准确率 68.7%，Top-3 准确率 96.7%。

**最终贡献 = 投篮期望 × 传球概率**

这个模型的好处是可解释——每个组件都有明确的物理意义，不是黑盒。验证方法：把所有回合按最高得分期望分成三组（全部、Top 5%、Bottom 5%），实际得分分别是 0.762、0.801、0.719 分，证明得分期望和实际得分正相关。

## 数据处理：从轨迹到聚类

OBTracker 用 NBA SportVU 数据集（631 场比赛，1.32 亿帧）。处理流程：

1. 识别持球者：每帧找离球最近的进攻球员（距离 < 3 英尺）
2. 提取切入者轨迹：过滤掉慢速移动（< 6 英尺/秒）和不在进攻半场的球员
3. 识别掩护者：如果一个无球球员在切入者经过时保持静止（< 3 英尺），标记为掩护者

聚类方法：把球场分成 21 个功能区（不是均匀网格，因为不同区域规则不同），把轨迹转化成功能区序列，去掉连续重复，得到聚类后的轨迹。

## 案例：LAC 队的三分线外跑位

教练用 OBTracker 分析 LAC 队，发现：
- LAC 队的无球跑动平均贡献最高（球队列表里黑条最长）
- 最常用且最有效的跑动是三分线外跑位，终点在左翼
- 底线切入（baseline cut）时，Stephenson 的投篮期望高，但传球概率低——他能跑到好位置，但持球者不敢传（防守干扰太多）
- 对比发现：从弱侧（球的另一边）开始底线切入，传球概率比从强侧（球的同侧）开始高得多

# 核心概念

## 得分期望的两步拆解

**一句话**：把"无球跑动的贡献"拆成"接到球后能得多少分"（投篮期望）和"能不能接到球"（传球概率），两者相乘得到得分期望。

**为什么重要**：这个拆解让评分变得可解释。如果一个球员得分期望低，你能看出是因为他跑到的位置不好（投篮期望低），还是因为持球者传不过去（传球概率低）。这比深度学习的黑盒模型更容易被教练信任。

## Voronoi 图的动态展示

**一句话**：用 Voronoi 图把球场分成每个球员的控制区域，按时间顺序排列多个 Voronoi 图，展示攻防态势的连续变化。

**类比**：就像看延时摄影，每一帧是一张 Voronoi 图，连起来看就能看到"防守者被甩开"或"切入者跑进空位"的过程。

**为什么重要**：无球跑动是动态过程，不是静态快照。传统篮球可视化（如 POINTWISE）只看持球者的某个时刻，OBTracker 用 Voronoi 图序列让教练能追踪整个跑动过程，理解"为什么这次跑位成功了"。

# 洞见

**无球跑动的价值不在结果，在过程**——传统统计只看"这次进攻得了几分"，但无球跑动的贡献可能在"创造了投篮机会但没传球"或"吸引了防守注意力让队友得分"。OBTracker 的得分期望模型能捕捉这些"没有直接体现在比分上"的贡献。这个洞见对任何需要评估"过程贡献"的场景都有意义——不只是篮球，足球的无球跑动、排球的掩护，都可以用类似的思路。

# 博导审稿

问题定位准确。无球跑动确实是篮球分析的盲区，传统统计看不到，视频分析太费时间。OBTracker 的三层视图设计清晰，从球队到球员到动作，符合教练的分析习惯。

评分模型的可解释性是亮点。投篮期望 = 支配区域 × 防守 × 投篮能力，每个组件都有物理意义。传球概率用线性回归，特征选择合理（距离、防守干扰）。验证方法也扎实——用实际得分验证得分期望的相关性。

但有一个根本性的限制：模型假设"球员接到球后立即投篮"。实际上很多球员接球后会运球、传球、或做其他动作。论文自己也承认这个问题（"some off-ball players control the ball themselves to attack"），但没有深入讨论这个假设的影响范围。

另一个问题：聚类方法用功能区序列，但功能区的划分是固定的（21 个区域）。不同球队的战术可能对区域有不同的理解，固定划分可能漏掉某些战术特征。

**判决：strong accept**。问题有价值，方法可解释，系统设计清晰，案例分析有说服力。是篮球可视化领域从"持球分析"走向"无球分析"的重要一步。

# 启发

**迁移**：OBTracker 的"得分期望 = 投篮期望 × 传球概率"框架可以迁移到足球的无球跑动分析——把"投篮期望"换成"射门期望"，把"传球概率"换成"传球成功率"。足球的无球跑动更复杂（11 人 vs 5 人），但核心思路一样：拆解贡献，让过程可见。

**混搭**：OBTracker 的 Voronoi 图动态展示 + FineDiving 的程序感知分段可以组合：把无球跑动分成多个阶段（起始、摆脱防守、到达位置），每个阶段用 Voronoi 图展示攻防态势变化。这比只看整体过程更细粒度，能定位"哪个阶段出了问题"。

**反转**：OBTracker 假设"无球跑动的目标是接球投篮"。但有些无球跑动的目标是"吸引防守注意力，让队友得分"——这种牺牲型跑位在 OBTracker 的模型里得分很低（因为自己没接到球），但对球队有贡献。反过来想：能不能加入"防守吸引力"指标，量化"这次跑位吸引了几个防守者"？这比只看个人得分期望更全面。
