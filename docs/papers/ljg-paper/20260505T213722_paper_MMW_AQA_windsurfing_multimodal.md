# 问题

AQA 数据集有两个共同的盲点，但没人同时解决过。

第一个盲点：只有视频，没有传感器数据。自由式帆板的动作是三维的——运动员在空中旋转，板和帆的姿态决定了动作质量。但摄像机只能拍到二维投影，3D 信息丢失了。

第二个盲点：视频都是固定视角拍的（侧面、正面）。真实场景里，无人机会绕着运动员飞，视角随时在变。现有方法在固定视角上训练，放到野外视角就失效了。

MMW-AQA 同时解决这两个问题：第一个多模态（视频 + IMU + GPS）的 AQA 数据集，视频由无人机从多变视角拍摄。

# 翻译

## 锚点：一个带传感器的无人机裁判

想象一个裁判，他不只用眼睛看，还在运动员的板和帆上贴了 IMU 传感器（测量三维旋转角度），同时用 GPS 记录运动员离岸边的距离（距离决定风力，风力决定动作难度）。他坐在无人机上，绕着运动员飞，从各个角度观察。

MMW-AQA 就是把这个裁判的感知系统数字化。

## 数据集：自由式帆板，三种模态

MMW-AQA 从 4 名职业运动员、3 个地点收集了 205 个自由式帆板动作样本，覆盖 14 种动作类型。

```
MMW-AQA 数据模态
├── 视频（UAV 拍摄，3840×2160@60fps）
│   -- 无人机绕运动员飞行，视角多变
├── IMU 数据（板 + 帆各一个传感器）
│   -- 三维旋转角度（pitch/roll/yaw）
│   -- 约 15-25fps，上采样到 30fps
└── GPS 数据（运动员离岸距离）
    -- 每个动作一个标量值
    -- 距离越近 = 风力越弱 = 动作越难

标注：3 名专业裁判打分（0-10.5，0.5 步长），取平均
```

和已有数据集比：所有已有 AQA 数据集都是单模态视频、固定视角。MMW-AQA 是第一个有 IMU 和 GPS 的 AQA 数据集，也是第一个用无人机拍摄的野外视角数据集。

## 方法：多模态化框架

论文提出了一个"插件式"多模态化框架：在现有单模态 AQA 模型的特征提取和评分模块之间，插入一个 Transformer 融合模块。

```
原始单模态模型：
特征提取（视频）→ 评分模块 → 分数

多模态化后：
特征提取（视频）→
特征提取（板 IMU）→  Transformer 融合模块 → 评分模块 → 分数
特征提取（帆 IMU）→
GPS 嵌入 →
```

Transformer 融合模块用多头自注意力学习不同模态之间的关系。每个模态的特征加上模态类型嵌入（防止 Transformer 混淆不同模态），再一起输入 Transformer。

这个框架的好处是：不需要重新设计模型，只需要在现有模型里插入融合模块，就能处理多模态输入。论文把这个框架应用到了 USDL、CoRe+GART、PCLN 三个已有模型上。

**效果**：所有三个模型加入多模态数据后性能都提升。最显著的是在"背面视角"（训练时没见过的视角）上——多模态模型的评分误差明显低于单模态模型，说明 IMU 数据提供了视角无关的 3D 信息，增强了鲁棒性。

# 核心概念

## 插件式多模态化框架

**一句话**：在现有单模态 AQA 模型里插入 Transformer 融合模块，让它能处理多模态输入，而不需要重新设计模型。

**变形过程**：单模态模型（只处理视频）→ 在特征提取后插入 Transformer 融合模块（把视频、IMU、GPS 特征拼在一起做自注意力）→ 融合后的特征送入原来的评分模块 → 多模态模型。整个过程只改了中间一层，前后不动。

**为什么重要**：这个框架让已有的 AQA 方法可以直接升级到多模态，不需要从头训练。对于 AQA 领域来说，这是一个实用的工程贡献——新数据集出来了，但不需要重新设计所有方法。

## IMU 数据的视角无关性

**一句话**：IMU 测量的是运动员的三维旋转角度，这个信息不依赖摄像机视角，是真正的 3D 信息。

**类比**：就像一个陀螺仪，不管你从哪个方向看它，它测量的旋转角度都是一样的。视频会因为视角变化而看起来完全不同，但 IMU 数据不会。

**为什么重要**：实验显示，在训练时没见过的背面视角上，多模态模型的误差明显低于单模态模型。这说明 IMU 数据提供了视角无关的 3D 信息，弥补了视频在未见视角上的失效。

# 洞见

**AQA 的鲁棒性问题不能靠更多视角的视频解决，而要靠视角无关的传感器数据**——无论收集多少视角的视频，总会有训练时没见过的视角。IMU 这类传感器数据不依赖视角，是真正的解决方案。这个洞见对任何需要在野外部署的 AQA 系统都有意义：如果运动员能戴传感器，传感器数据比多视角视频更可靠。

# 博导审稿

问题定位准确，数据集有创意。自由式帆板是一个很好的选择——它天然需要 3D 信息（空中旋转）和野外视角（海上无人机），两个问题在一个运动里都能验证。

但有一个根本性的限制：205 个样本太少了。论文自己也承认这个问题，并把"构建更大的多模态数据集"列为未来工作。在这么小的数据集上，实验结论的可靠性存疑——多模态的提升可能是过拟合，也可能是随机波动。

另一个问题：GPS 数据只是一个标量（离岸距离），但论文把它和 IMU 的时序数据一起送入 Transformer。一个标量和时序特征做自注意力，这个设计是否合理？论文没有分析 GPS 数据的实际贡献。

**判决：weak accept**。数据集有创意，框架实用，但样本量太小，结论可靠性不足。作为概念验证有价值，但需要更大规模的验证。

# 启发

**迁移**：MMW-AQA 的"插件式多模态化框架"可以直接用在任何已有 AQA 模型上——如果你有一个在 FineDiving 上训练好的模型，想加入骨架数据，用这个框架插入 Transformer 融合模块，比重新设计模型更快。

**混搭**：MMW-AQA 的 IMU 数据 + FLEX 的 sEMG 数据可以组合：IMU 测量外部运动（板和帆的旋转），sEMG 测量内部肌肉激活。两者结合能同时捕捉"动作做了什么"和"肌肉怎么发力"，比任何单一传感器都更完整。

**反转**：MMW-AQA 假设"IMU 传感器贴在工具上（板和帆）"。但对于没有工具的运动（跳水、体操），IMU 需要贴在运动员身上，这会影响动作。反过来想：能不能用视频估计 IMU 信号（类似 FLEX 的 Video→EMG 任务），而不是真的贴传感器？如果视频能预测 IMU，就能在不影响运动员的情况下获得 3D 信息。
