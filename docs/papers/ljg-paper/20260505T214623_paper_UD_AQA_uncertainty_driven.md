# 问题

AQA 评分时，7 个裁判给出的分数不完全一样——有人给 7 分，有人给 7.5 分，有人给 8 分。这种分歧不是错误，是主观性。

现有 AQA 方法都是确定性模型——输入一个视频，输出一个分数。但这忽略了裁判之间的分歧。有些方法用多头网络（每个头预测一个裁判的分数），但这不灵活——如果需要 10 个裁判的分数，就得重新训练 10 个头。

UD-AQA 的思路是：用概率模型捕捉裁判之间的不确定性，通过采样生成多个分数，而不是只输出一个。

# 翻译

## 锚点：一个会模拟多个裁判的评分系统

想象一个 AI 裁判，他不只给一个分数，而是模拟 7 个真实裁判的打分过程。他知道"这个动作在 7-8 分之间"，然后从这个分布里采样 7 次，生成 7 个略有差异的分数——就像 7 个真实裁判各自打分一样。

UD-AQA 就是把这个过程数字化：用 CVAE 学一个潜在空间，这个空间编码了"裁判之间的分歧"，每次从这个空间采样，就能生成一个新的分数。

## 两条分支：确定性 + 不确定性

UD-AQA 有两条分支：

```
确定性分支（Deterministic Branch）
├── I3D 提取片段特征
├── 加权注意力模块聚合成视频特征 f_v
└── 输出确定性特征

不确定性分支（Latent Branch，基于 CVAE）
├── 先验网络 P(z|X)：从视频 X 学潜在变量 z
├── 后验网络 Q(z|X,y)：从视频 X 和分数 y 学潜在变量 z
├── 训练时：最小化先验和后验的 KL 散度
└── 测试时：从先验网络采样 z，生成不确定性特征 f_u

融合 + 预测
├── 拼接 f_v 和 f_u
├── MLP 回归器输出预测分数
└── 多次采样 → 多个预测分数
```

**关键设计**：训练时，每次随机从裁判分数集合里抽一个分数作为标签。测试时，多次采样生成多个分数。

## 不确定性的两个用途

**用途 1：重加权损失**

把潜在变量 z 映射成一个标量 u（不确定性估计）。用 e^(-u) 作为回归损失的权重：
- 不确定性低 → 权重高 → 这个样本更可靠，多学
- 不确定性高 → 权重低 → 这个样本不可靠，少学

损失函数：L_RAQA = e^(-u) ||ŷ - y||_2 + u

**用途 2：课程学习**

按不确定性从低到高排序样本，先训练低不确定性的样本（简单样本），再逐步加入高不确定性的样本（困难样本）。

具体策略：第一轮训练后记录每个样本的不确定性，第二轮开始用 40% 的数据（最低不确定性），收敛后增加 20%，直到用完全部数据。

## 效果

MTL-AQA：SRCC 0.9545（超过 MUSDL 的 0.9273，提升 2.72%）
FineDiving：SRCC 0.9341（超过 TSA-15 的 0.9204，提升 1.37%）
JIGSAWS：平均 SRCC 0.87（Suturing）、0.93（Needle-Passing）、0.86（Knot-Tying）

# 核心概念

## CVAE 编码不确定性

**一句话**：用条件变分自编码器（CVAE）把"视频 + 裁判分数"映射到一个潜在空间，从这个空间采样就能生成多样化的分数。

**变形过程**：确定性模型（视频 → 单一分数）→ 加入 CVAE（视频 → 潜在空间 → 采样 → 多个分数）→ 每次采样相当于模拟一个裁判的打分过程。

**为什么重要**：CVAE 的生成能力让模型能输出多个分数，而不需要为每个裁判训练一个独立的头。这比多头网络更灵活——需要几个分数就采样几次，不需要重新训练。

## 不确定性引导的课程学习

**一句话**：按样本的不确定性从低到高排序，先训练确定性高的样本，再逐步加入不确定性高的样本。

**类比**：就像学数学，先做简单题（答案明确），再做难题（答案模糊）。模型先从"裁判意见一致"的样本学起，再学"裁判意见分歧大"的样本。

**为什么重要**：传统课程学习用人工定义的难度（如动作复杂度），UD-AQA 用模型自己预测的不确定性作为难度指标。这个指标是动态的——每轮训练后重新计算，比固定难度更适应模型的学习状态。

# 洞见

**AQA 的不确定性不是噪声，是信号**——裁判之间的分歧不是需要消除的噪声，而是任务本身的特性。UD-AQA 把这种分歧编码进模型，反而提升了性能。这个洞见对任何有主观评价的任务都有意义——不要强行把多个标注者的意见平均成一个"真值"，而是保留分歧，让模型学会这种分歧的模式。

# 博导审稿

问题定位准确。裁判之间的分歧确实是 AQA 的固有特性，现有方法要么忽略（只用平均分），要么用多头网络（不灵活）。UD-AQA 用 CVAE 建模不确定性，思路清晰。

方法设计合理。CVAE 的先验网络和后验网络分别在测试和训练时使用，KL 散度让两者对齐。不确定性的两个用途（重加权损失 + 课程学习）都有理论支撑。

但有一个根本性的问题：CVAE 学到的潜在空间真的编码了"裁判之间的分歧"吗？论文没有可视化潜在空间，也没有分析采样出来的多个分数是否真的符合裁判分数的分布。如果只是随机扰动，那 CVAE 的作用就打折扣了。

另一个问题：不确定性估计用的是潜在变量 z 映射成的标量 u，但 z 是多维的（D=6），映射成一维会丢失信息。为什么不直接用 z 的方差作为不确定性？

**判决：weak accept**。思路有创意，实验结果好，但缺少对 CVAE 学到的潜在空间的深入分析。作为方法论文可以接受，但需要补充可视化和分析。

# 启发

**迁移**：UD-AQA 的"用 CVAE 建模标注者分歧"框架可以迁移到任何有多个标注者的任务——医学图像分割（多个医生标注）、情感分析（多个标注者打分）、代码质量评估（多个审查者评分）。关键是把"分歧"当作信号而不是噪声。

**混搭**：UD-AQA 的不确定性估计 + FineDiving 的程序感知分段可以组合：对每个子动作分别估计不确定性，找出"裁判分歧最大的子动作"。这能定位"哪个环节最难评分"，对运动员训练有指导意义。

**反转**：UD-AQA 假设"不确定性高的样本应该降低权重"。但反过来想：不确定性高的样本可能包含更多信息——正是因为难评分，才需要模型学会区分细微差别。能不能设计一个"先降权再升权"的策略：早期降权（避免噪声），后期升权（学习细节）？
