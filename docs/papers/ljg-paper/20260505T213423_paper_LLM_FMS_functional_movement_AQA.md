# 问题

FMS（功能性动作筛查）是运动医学里用来预防运动损伤的标准工具。它有 7 个基本动作，每个动作打 0-3 分，总分反映一个人的基础运动能力。

问题是：现有的自动化 FMS 评估只能给出一个数字，说不清楚"为什么是 2 分而不是 3 分"。运动员拿到分数，不知道该改哪里。这不是技术问题，是数据问题——现有 FMS 数据集只有总分，没有"哪个关节角度不对、哪个身体部位出了问题"的细粒度标注。

LLM-FMS 就是来填这个坑的：第一个有三层语义标注的 FMS 数据集，配套用 LLM 做可解释评分的框架。

# 翻译

## 锚点：一个会说话的 FMS 裁判

想象一个 FMS 专家，他不只说"你的深蹲是 2 分"，还说"你的躯干和小腿的夹角是 45 度，标准是平行（0 度），所以扣 1 分；你的髋关节没有低于膝关节，这是第二个扣分点"。

LLM-FMS 就是把这个专家的判断过程数字化：先标注出"哪些角度/位置关系决定分数"，再用 LLM 按这些规则推理并生成解释。

## 数据集：三层语义结构

LLM-FMS 从 45 名受试者的 FMS 视频里提取了 1812 个关键帧图像，覆盖 15 个动作（7 种 FMS 动作，部分动作左右各做一次）。

每个关键帧有三层标注：

```
LLM-FMS 标注层级（以深蹲为例）
├── 第一层：分数（1/2/3）
├── 第二层：评分细节
│   ├── 角度 1：躯干-小腿夹角（躯干应与小腿平行）
│   ├── 位置 1：髋关节高度（髋应低于膝）
│   └── 位置 2：手腕位置（手腕应在膝关节右侧）
└── 第三层：涉及的身体部位
    ├── 躯干
    ├── 左下肢
    └── 右下肢
```

关键帧提取方法：用 RTMPose 提取 17 个骨架关键点，计算每帧和标准关键帧之间的余弦相似度，选距离最小的帧作为关键帧。

## 方法：规则 + LLM 推理

```
输入：FMS 动作视频
    |
[RTMPose 提取骨架关键点]
    |
[关键帧识别（余弦相似度）]
    |
[按专家规则计算评分指标]
    ├── 关节角度（如躯干-小腿夹角）
    ├── 位置关系（如髋关节是否低于膝关节）
    └── 距离特征（关节间距离）
    |
[生成 Prompt]
    ├── 评分规则（专家知识库）
    └── 用户动作的具体指标值
    |
[LLM 推理]
    |
输出：分数（1/2/3）+ 详细解释 + 改进建议
```

这个框架的核心思路是：不让 LLM 直接看视频，而是先用规则把视频转化成结构化的关节角度/位置信息，再让 LLM 按规则推理。LLM 在这里是推理引擎，不是特征提取器。

**效果**：平均准确率 0.91，maF1 0.87，Kappa 0.82，超过所有已有 FMS 评估方法（最好的对比方法准确率 0.89）。

# 核心概念

## 规则驱动的 LLM 推理（Rule-Guided LLM Reasoning）

**一句话**：先用专家规则把视频转化成结构化指标，再让 LLM 按规则推理打分，而不是让 LLM 直接从视频里学打分。

**变形过程**：端到端深度学习（视频 → 分数，黑盒）→ 规则提取指标（视频 → 关节角度/位置，可解释）→ LLM 推理（指标 + 规则 → 分数 + 解释，可追溯）。每一步都在把"隐式知识"变成"显式推理"。

**为什么重要**：深度学习方法准确率 0.88-0.89，LLM 方法 0.91，而且 LLM 方法能说清楚"为什么"。这说明在有明确规则的评分任务上，规则 + LLM 比端到端学习更准、更可解释。

## 关键帧提取（Keyframe Extraction）

**一句话**：从动作视频里找到最能代表动作质量的那一帧，而不是处理整段视频。

**类比**：就像一个裁判，他不需要看完整个深蹲过程，只需要看"最低点"那一帧就能判断髋关节是否低于膝关节。关键帧提取就是自动找到这个"最低点"。

**为什么重要**：FMS 评分本质上是对特定姿态的评估，不是对动作过程的评估。用关键帧代替整段视频，既减少了计算量，又让评分指标更精确——角度和位置关系在关键帧上最清晰。

# 洞见

**LLM 在 AQA 里最有价值的用途不是特征提取，而是规则推理**——当评分规则可以被明确表达时，把规则编码进 Prompt 让 LLM 推理，比让模型从数据里隐式学规则更准确、更可解释。这个洞见的边界条件是：规则必须能被明确表达。对于有官方评分手册的运动（FMS、跳水、体操），这个方法直接可用；对于规则模糊的运动（街舞、即兴表演），这个方法不适用。

# 博导审稿

数据集贡献有价值，但规模太小。1812 个关键帧、45 名受试者——这个规模对于训练深度学习模型来说不够，但对于验证 LLM 推理框架来说够用。论文的定位是"第一个细粒度 FMS 数据集"，这个定位是准确的。

方法上，规则 + LLM 的思路清晰，但有一个根本性的问题没有讨论：这个方法的性能上限是专家规则的质量。如果专家规则不完整（比如漏掉了某些扣分情况），LLM 再强也无法弥补。论文没有分析规则覆盖率，也没有讨论规则不完整时的失败案例。

另一个问题：关键帧提取用余弦相似度匹配标准帧，这假设"最接近标准帧的帧就是关键帧"。但对于得分低的动作，关键帧可能和标准帧差异很大，余弦相似度最小的帧不一定是评分最关键的帧。论文没有验证关键帧提取的准确性。

**判决：weak accept**。数据集贡献有价值，LLM 推理框架思路清晰，但规模小、方法假设未验证。作为概念验证有意义，但距离实用还有距离。

# 启发

**迁移**：LLM-FMS 的"规则 → 指标 → Prompt → LLM 推理"框架可以直接用在任何有明确评分规则的运动上。如果你在做 AQA，先问：这个运动的评分规则能不能被表达成"如果角度 X 大于阈值 Y，则扣 Z 分"的形式？能的话，这个框架比端到端深度学习更可解释，而且不需要大量标注数据。

**混搭**：LLM-FMS 的规则推理 + FLEX 的 sEMG 数据可以组合：用 LLM 推理判断"外部动作是否符合规则"，用 sEMG 判断"内部肌肉是否正确激活"。两层诊断——规则符合性 + 肌肉激活——比任何一层单独都更完整。

**反转**：LLM-FMS 假设"关键帧包含了评分所需的全部信息"。但 FMS 里有些评分项需要看动作过程（比如"动作是否流畅"），不是单帧能判断的。反过来想：哪些 FMS 评分项是静态的（可以用关键帧），哪些是动态的（需要看过程）？先做这个分类，再分别用不同的方法处理，比统一用关键帧更准确。
