# 问题

AQA 这个领域做了十几年，论文散落在体育、手术、康复三个完全不同的应用场景里，互相看不见。

做跳水 AQA 的人不知道手术技能评估那边有什么好方法，做康复训练评估的人不知道体育那边的数据集能不能用。每个子领域都在重复造轮子，却没有人把这张地图画出来。

这篇综述用 PRISMA 系统文献综述方法，把 96 篇论文整理成一张地图，回答：这个领域做了什么、用什么方法、还差什么。

# 翻译

## 锚点：一个图书管理员在整理三个书架

想象一个图书管理员面对三个书架：体育（53 本）、手术（13 本）、康复（13 本）。书的内容不同，但解决的是同一类问题——"这个动作做得好不好"。管理员的工作是：找出这些书共用的分类逻辑，画一张索引，告诉你每本书在哪、讲什么、和哪本书有关联。

这篇综述就是这个图书管理员。

## 地图：按方法分，不按应用分

以前的综述按应用分（体育/手术/康复），结果同一套方法在三个章节里各讲一遍。这篇综述换了维度：**按输入数据和方法分**。

```
AQA 方法
├── 骨架方法
│   ├── 传统方法（DTW、HMM、SVM）
│   │   -- 用关节角度、速度等手工特征
│   └── 深度学习方法
│       ├── RNN/LSTM（时序建模）
│       └── GCN（图卷积，把骨架当图处理）
└── 视频方法
    ├── 2D CNN（逐帧提特征）
    ├── 3D CNN / I3D（时空联合建模）
    │   -- I3D 是使用最多的骨干网络（28/96 篇）
    ├── Transformer（全局时序关联）
    └── 对比学习（和参考视频比较）
```

这个分法的好处：同一类方法面对的工程挑战是一样的，可以直接比较设计思路。

## 数字：这个领域长什么样

96 篇论文里：
- 体育 53 篇（最多），手术 13 篇，康复 13 篇，其他 17 篇
- 评估指标：SRCC 最常用（56/96 篇），其次是 MSE/MAE
- 骨干网络：I3D 最多（28 篇），其次是 C3D（14 篇）
- 数据集：MTL-AQA 最常用，其次是 AQA-7 和 FineDiving
- 时间跨度：2014-2024，2020 年后论文数量明显增加

## 三个应用场景的差异

**体育**：数据最多，方法最成熟。主要挑战是细粒度识别（三周跳还是四周跳）和长时序建模（体操地板动作两分钟）。

**手术**：数据最少，标注最贵。主要挑战是隐私（手术视频不能公开）和标注专业性（只有外科医生能打分）。方法上更依赖骨架，因为手部动作比整体姿态更重要。

**康复**：介于两者之间。主要挑战是个体差异——同一个康复动作，不同患者的"正确"标准不同（受伤程度不同）。

## 四个开放问题

1. **数据稀缺**：高质量标注数据少，尤其是手术和康复场景。半监督和自监督方法是出路
2. **可解释性**：光给分数没用，要告诉用户"哪里做错了"。现有方法大多是黑盒
3. **跨域泛化**：在跳水上训练的模型，放到体操上就失效。领域自适应是开放问题
4. **实时性**：大多数方法离线处理，实时反馈需要轻量化模型

# 核心概念

## PRISMA 系统文献综述

**一句话**：一套标准化的文献筛选流程，确保综述覆盖全面、筛选透明、结论可复现。

**变形过程**：随机搜索（可能漏掉重要论文）→ 定义关键词 + 数据库（Scopus、IEEE Xplore、Web of Science）→ 按标题/摘要/全文三轮筛选 → 记录每轮筛掉多少篇、为什么筛掉 → 最终 96 篇入选。

**为什么重要**：没有这套流程，综述作者可能无意识地偏向自己熟悉的方向，漏掉某个子领域的重要工作。PRISMA 让综述的覆盖范围可以被质疑和验证。

## I3D（双流膨胀 3D 卷积）

**一句话**：把 2D 图像分类网络"膨胀"成 3D，同时处理空间和时间信息。

**变形过程**：2D CNN（只看单帧）→ 把所有 2D 卷积核扩展一个时间维度变成 3D 卷积核 → 同时处理 RGB 流和光流流 → 得到时空联合特征。

**为什么重要**：I3D 是 AQA 领域使用最广的骨干网络（28/96 篇），因为它在 Kinetics 上预训练，迁移到 AQA 任务时特征质量高，而且有大量开源实现可以直接用。

# 洞见

**AQA 的真正瓶颈不是模型不够强，而是"分数"这个标注形式本身太弱**——一个数字压缩了裁判的全部判断，模型从这个数字里能学到的东西有限。可解释 AQA（告诉用户哪里做错了）才是让这个技术真正有用的方向，但在 96 篇论文里占比最少。

# 博导审稿

PRISMA 方法论是这篇综述最大的优点。明确的检索策略、三轮筛选、筛选理由记录——这让综述的覆盖范围可以被验证，比"我们调研了相关工作"这种模糊说法严谨得多。

跨应用场景的视角也有价值。把体育、手术、康复放在同一个框架下分析，读者能看到方法层面的共性，而不是被应用场景的差异遮住。

但有几个问题。第一，分析深度不均匀。体育部分覆盖详细，手术和康复部分明显偏薄，可能是因为作者本身的研究背景在体育方向。第二，"未来方向"部分列了四个方向，但每个都只有一段话，缺乏对可行性的判断——哪个方向现在就能做，哪个还差关键技术，没有说清楚。第三，综述截止到 2024 年，但 2023-2024 年 LLM 和多模态大模型在 AQA 里的应用开始出现，这部分覆盖不足。

**判决：weak accept**。方法论严谨，覆盖面广，但分析深度不均，对新兴方向的覆盖滞后。作为入门参考有价值，但不如同年的 Zhou et al. 综述（arXiv 2412.11149）深入。

# 启发

**迁移**：PRISMA 的三轮筛选流程可以直接用来做任何领域的文献调研——先定关键词，再按标题/摘要/全文三轮过滤，记录每轮筛掉多少篇。这个流程让调研结果可以被质疑和复现，比随机搜索靠谱得多。

**混搭**：这篇综述指出"手术 AQA 数据稀缺"，但体育 AQA 数据相对丰富。可以试试跨域迁移：在体育数据上预训练，再用少量手术数据微调。两个领域的"动作质量"概念有共性（流畅性、准确性、节奏），迁移可能比从头训练更有效。

**反转**：综述里 56/96 篇论文用 SRCC 作为评估指标，但 SRCC 衡量的是排名相关性，不是绝对误差。对于康复训练这种需要"你的膝盖弯曲角度差了 15 度"的应用，SRCC 高不代表反馈有用。反过来想：应该用 MAE 或者关节角度误差来评估，而不是追求 SRCC 排行榜。
