# 问题

视频理解有两条路，但没人把它们接起来。

第一条路：掩码视频建模（VideoMAE）——自监督，擅长动作识别，但不懂语义。第二条路：视频-语言对比学习（CLIP 系列）——懂语义，但时序建模弱。两条路各有擅长，各有盲区，但研究者通常只走一条。

能不能把两条路的优势合并？直接联合训练行不通——MAE 和对比学习的优化目标互相冲突，批量大小要求也不同。InternVideo 的答案是：分开训练，再用跨模型注意力把两个模型的特征融合起来。

# 翻译

## 锚点：两个专家 + 一个翻译官

想象两个专家：一个是动作分析师（VideoMAE），他看视频能精确识别"这个人在做什么动作"，但不懂语言；另一个是语言理解专家（CLIP-UniFormerV2），他能把视频和文字对应起来，但对细粒度动作不够敏感。

InternVideo 不是让这两个专家合并成一个人，而是雇了一个翻译官（跨模型注意力，CMA），让他们在各自擅长的领域独立工作，需要时互相借力。

## 三阶段训练

```
阶段 1：分开预训练
├── 掩码视频编码器（VideoMAE-Huge）
│   -- 90% 掩码率，重建像素，学时空特征
│   -- 在 UnlabeledHybrid（12M 视频）上训练
└── 多模态视频编码器（UniFormerV2 + CLIP）
    -- 视频-文本对比 + 字幕生成
    -- 在 WebVid + HowTo100M + LAION-100M 上训练

阶段 2：监督后预训练
├── 两个编码器分别在 Kinetics-710 上做动作分类微调
└── Kinetics-710 = K400 + K600 + K700 合并去重（650K 视频，710 类）

阶段 3：跨模型交互（CMA）
├── 冻结两个编码器的主体
├── 加入跨模型注意力模块（MHCA + FFN）
│   -- 掩码编码器的中间特征作为 Query
│   -- 多模态编码器的中间特征作为 Key/Value
│   -- 最后一层反过来：多模态 class token 从掩码编码器借信息
└── 只训练 CMA 模块，5 个 epoch
```

这个设计的好处：两个编码器的优化目标不冲突，各自训练到最优；CMA 只是一个轻量的融合层，训练成本低。

## 结果：39 个数据集全面 SOTA

InternVideo 在三类任务上都达到 SOTA：

**动作理解**：K400 91.1%（+1.2% vs 之前最好），SSv2 77.2%（+1.6%），ActivityNet 94.3%（+4.1%）。

**视频-语言对齐**：MSR-VTT 检索 R@1 55.2%（+5.9% vs X-CLIP），视频问答 MSRVTT 47.1%（+3.2%）。

**开放世界理解**：视觉语言导航（VLN-CE）成功率 52.9%（+2.7%），Ego4D 五个赛道冠军。

# 核心概念

## 跨模型注意力（Cross-Model Attention, CMA）

**一句话**：用注意力机制让两个独立训练的编码器互相借用中间特征，而不是把它们合并成一个模型。

**变形过程**：两个独立编码器（各自输出特征，简单加权融合）→ 在中间层插入 CMA（掩码编码器的特征作为 Query，多模态编码器的特征作为 Key/Value）→ 掩码编码器的每一层都能"看到"多模态编码器对应层的语义信息 → 最后一层反向：多模态 class token 从掩码编码器借时序信息。

**为什么重要**：直接加权融合两个编码器的输出是"事后补救"，CMA 是"过程中协作"。中间层的特征比最终输出包含更多细节，CMA 让两个编码器在特征层面互相增强，而不只是在预测层面投票。

## 统一视频表示（UVR）范式

**一句话**：用生成式（MAE）和判别式（对比学习）两种自监督方式分别学习，再通过监督学习和跨模型交互统一成一个表示。

**类比**：就像一个学生同时学理科（MAE，从数据本身学规律）和文科（对比学习，从标签和语言学关系），两种学习方式互补，最后综合考试（下游任务）时都能用上。

**为什么重要**：单一预训练目标有盲区——MAE 不懂语义，对比学习不懂时序细节。UVR 通过组合两种目标，覆盖了视频理解的更大范围，在 39 个数据集上全面超越只用一种目标的方法。

# 洞见

**视频基础模型的关键不是更大的模型，而是更好的特征组合策略**——InternVideo 用 1.3B 参数在 39 个数据集上全面超越了更大的模型（CoCa 1B+、MTV-H 1B+），因为它把两种互补的特征有效融合了。这个洞见意味着：在资源有限的情况下，与其训练一个更大的单一模型，不如训练两个互补的中等模型再融合。

# 博导审稿

工程贡献扎实。39 个数据集、10 个任务、全面 SOTA——这个覆盖面在 2022 年是前所未有的。Kinetics-710 数据集的构建也是一个有价值的贡献，后续工作可以直接用。

CMA 的设计思路清晰，但有一个值得追问的地方：CMA 只训练 5 个 epoch，参数量很小，但贡献了多少性能提升？论文没有单独消融 CMA 的贡献，只报告了最终结果。如果 CMA 的贡献主要来自简单的特征融合而不是跨层交互，那这个设计的复杂性就不值得。

另一个问题：两个编码器分开训练，意味着它们的特征空间可能不对齐。CMA 需要学会在不对齐的特征空间之间做翻译，这个学习难度没有被讨论。

**判决：strong accept**。覆盖面广，结果扎实，是视频基础模型领域的里程碑工作。CMA 的设计有创意，但消融分析不够深入。

# 启发

**迁移**：InternVideo 的特征（尤其是 CMA 融合后的特征）对 AQA 任务有直接价值。现有 AQA 方法用 I3D 提特征，换成 InternVideo 的特征，动作识别能力（K400 91.1%）和语义理解能力（视频检索 SOTA）都更强，应该能直接提升 AQA 性能。

**混搭**：InternVideo 的"分开训练 + CMA 融合"框架可以用在 AQA 的多模态融合上——把视频编码器和骨架编码器分开训练到各自最优，再用 CMA 融合，而不是从头联合训练。这比联合训练更稳定，也更容易调试。

**反转**：InternVideo 假设"两种预训练目标互补"。但在 AQA 这种细粒度评分任务上，MAE 学到的时空特征和对比学习学到的语义特征，哪个更重要？反过来想：与其无差别融合，不如先在 AQA 数据集上测试两种特征各自的性能，再决定融合权重。如果 MAE 特征在 AQA 上明显更好，CMA 的融合可能反而引入噪声。
