# 动作质量评估（AQA）研究进展

## 一、定义与核心问题

AQA 与传统动作识别（HAR）的本质区别：

| 任务 | 问题 | 输出 |
|------|------|------|
| 动作识别 | 做了什么动作？ | 类别标签 |
| 动作质量评估 | 动作做得怎么样？ | 质量分数 / 排序 / 细粒度诊断 |

AQA 是细粒度学习任务，需要捕捉同类动作之间的微弱质量差异，而非区分不同类别。

---

## 二、技术演进三阶段

**阶段一：手工特征 + 浅层模型（2014 年前）**

- 特征：光流、HOG3D、关节轨迹、关节角度
- 模型：SVM、SVR、核回归
- 局限：泛化性差，只能处理固定视角的标准化动作

**阶段二：深度学习爆发（2014–2020）**

- 主干网络：C3D → I3D → SlowFast
- 关键进展：
  - 2017 年 Parmar 等用 C3D+SVR 开启深度学习 AQA 时代
  - 2017 年 Bertasius 等引入**配对排序**范式
  - SRCC 从 0.6 提升至 0.9 以上
- 局限：对细粒度时序结构利用不足，难以解释评分依据

**阶段三：Transformer + 多模态通用化（2021–至今）**

- 核心突破：
  - 长时序复合动作的建模能力
  - 从"给分"到"纠错+指导"的可解释性
  - 少样本/零样本泛化能力
- 代表工作：Temporal Parsing Transformer（ECCV 2022）、CoFInAl、MAGR++

---

## 三、主流技术路线

### 1. 特征提取

- **3D CNN（C3D/I3D/SlowFast）**：同时捕获空间外观和帧间运动，是早期主流
- **骨骼 + GCN**：将关节视为节点、骨骼视为边，构建时空图，对背景/服装鲁棒
  - ST-GCN 及变体：建模人体部位协调性和时间演化
  - 部分级别 GCN（PL-GCN）：可学习图池化，自动聚合关键关节
- **Transformer**：建模长程依赖，易于扩展至多模态输入

### 2. 回归范式

| 范式 | 核心思路 | 优势 |
|------|----------|------|
| 绝对分回归 | 直接预测质量分数（MSE 损失） | 可提供具体分数 |
| 对比回归（CoRe） | 预测与参考视频的**相对分差** | 降低拍摄条件噪声，关注真正的质量差异 |
| 分布回归（USDL） | 预测分数的**概率分布**而非单点值 | 建模裁判主观差异，提供置信度 |

**对比回归**是近年最重要的突破：与其预测绝对分，不如通过对比查询视频与参考示例的差异来回归相对分，多个参考示例聚合得到更稳健的最终得分。

### 3. 时序建模

- **阶段分解**：将动作分割为子动作（如跳水的起跳→空中→入水），分别评估再融合
- **时序解析 Transformer（TPT）**：可学习 query 自适应切分视频为多个时间段
- **管状自注意力（TSA-Net）**：在 3D 时空中捕捉单目标的长期依赖

### 4. 多模态融合

| 模态组合 | 适用场景 |
|----------|----------|
| RGB + 骨骼 | 通用运动评估 |
| RGB + 音频 | 花样滑冰（动作-音乐协调性） |
| RGB + IMU/sEMG | 健身、举重（深层发力评估） |
| 多视角 RGB | 艺术体操、艺术游泳 |

## 四、主要数据集

| 数据集 | 运动项目 | 规模 | 核心特点 |
|--------|----------|------|----------|
| AQA-7 | 跳水/体操/滑雪等 7 类 | 1,189 | 早期多动作基准 |
| MTL-AQA | 跳水 | 1,412 | 多任务标注（难度+分数+文本） |
| **FineDiving** | 跳水 | 3,000 | **首个过程感知数据集**，提供子动作阶段标注 |
| Diving48 | 跳水 | 18,404 | 超大规模，细粒度动作识别 |
| SkatingVerse | 花样滑冰 | 11,671 | 识别+分割+评估全方位基准 |
| LOGO | 艺术游泳 | 200 | 多人长视频，首推群体 AQA |
| FLEX | 健身训练 | 7,512 | 多模态（RGB+sEMG+3D），20 类动作 |
| LucidAction | 8 类体育 | - | 多视角+多模态+课程学习标注 |
| FineSkiing | 空中技巧滑雪 | - | 详尽扣分项描述和技术阶段划分 |

**FineDiving** 是里程碑式数据集：将每次跳水标注为连续阶段并关联语义标签，开启了"可解释评价"时代。

---

## 五、评估指标

- **SRCC（Spearman 等级相关系数）**：最核心指标，衡量预测排序与专家排序的一致性，对非线性关系鲁棒
- **R-L2（相对 L2 距离）**：标准化误差，支持跨数据集比较
- **MSE/RMSE**：衡量绝对分数预测偏差

当前主流数据集上，先进方法的 SRCC 已普遍达到 **0.9 以上**。

## 六、细分运动场景进展

**竞技打分类（跳水/体操/花样滑冰）**
- 最成熟的 AQA 应用场景
- 跳水：HP-MCoRe 在 FineDiving 上 SRCC 达 0.982，接近人类裁判一致性
- 花样滑冰：需要音视频联合建模（动作-音乐协调性），长程依赖建模是关键

**球类运动（篮球/乒乓球/足球）**
- 核心难点：人-球交互的联合评估
- 需要同时评估动作规范性和动作效果（"蒙进的错误动作"vs"没进的标准动作"）

**大众健身与康复**
- 关注动作"正确性"和"预防伤害"，而非极致表现
- 可解释性要求高，需要生成具体改进建议
- 已落地到 Keep 等健身 APP 的 AI 教练功能

**武术/舞蹈**
- 除动作规范性外，还需量化节奏、力度、风格等主观维度
- 国内研究处于全球领先地位

## 七、核心挑战与未来方向

**当前挑战：**
1. **数据稀缺**：专家标注成本高，大规模高质量数据集仍少
2. **评分主观性**：裁判间差异难以消除，需要不确定性建模
3. **跨领域泛化**：单一项目训练的模型难以迁移
4. **可解释性**：运动员需要的是"为何扣分"而非仅仅一个分数
5. **实时性**：边缘设备部署对计算效率要求高

**未来方向：**
- **多模态深度融合**：视觉 + IMU + sEMG + 音频的全面感知
- **LLM 驱动的可解释 AQA**：从"打分"到"打分-错误定位-自然语言指导-训练方案生成"全闭环
- **通用运动 AQA 大模型**：覆盖全品类运动、支持零样本评估
- **3D 数字孪生**：单目摄像头实现人体动作 3D 重建，解决视角受限问题
- **自监督/弱监督学习**：减少对大量标注数据的依赖

---

## 对花式足球教练系统的启示

结合项目背景，花式足球 AQA 的技术路线建议：

1. **姿态估计**：MediaPipe 或 MMPose 提取 2D/3D 关键点
2. **动作分解**：将花式动作分解为基本单元（颠球/绕球/停球），分阶段评估
3. **评估核心**：轨迹平滑度 + 关节角度合理性 + 与标准动作的相似度（对比回归）
4. **反馈生成**：基于错误类型知识库，生成具体可操作的改进建议

AQA 领域正从"评分工具"向"AI 教练系统"演进，这与花式足球教练系统的目标高度契合。
