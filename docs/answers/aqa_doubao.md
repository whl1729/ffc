# 动作质量评估（AQA）领域研究进展（聚焦运动场景）
**动作质量评估（Action Quality Assessment, AQA）** 是计算机视觉与模式识别领域的核心细分方向，核心目标是从视频/多模态传感数据中，**自动量化评估人体动作的执行规范性、熟练度、完成度与竞技水平，同时定位动作缺陷、输出可解释的改进方案**。它与传统动作识别有本质区别：动作识别解决“做了什么动作”，而AQA解决“动作做得好不好、差在哪里、如何优化”，是当前AI辅助运动训练、竞技体育智能裁判、大众健身指导的核心底层技术。

---

## 一、领域整体发展脉络
截至2026年，AQA领域已完成三次技术迭代，从实验室概念验证进入规模化商业落地阶段，其中运动场景是AQA技术落地最成熟、研究最深入的核心赛道：
1.  **传统方法阶段（2010年前）**：基于手工特征（光流、HOG3D、关节轨迹），用SVM、传统回归模型做简单评分，仅能处理固定视角、短时长的标准化动作（如跳水、体操），泛化性差，应用局限于实验室场景。
2.  **深度学习爆发期（2014-2020）**：以3D CNN、LSTM、时空图卷积网络（ST-GCN）为核心，实现端到端的动作特征提取与评分回归。这一阶段诞生了MTL-AQA、FineDiving等经典体育数据集，模型从“全局打分”进化到“子动作细粒度评估”，与专业裁判评分的斯皮尔曼等级相关系数（SROCC）从0.6提升至0.9以上，开始落地到竞技体育辅助裁判场景。
3.  **大模型与多模态通用化阶段（2021-至今，2024-2026年迎来爆发）**：以Transformer、多模态大模型、对比学习为核心技术，突破了三大核心瓶颈：① 长时序复合动作的评估能力；② 模型的可解释性（从“给分”到“纠错+指导”）；③ 少样本/零样本泛化能力。多模态融合成为主流，AQA从竞技体育拓展到大众健身、舞蹈武术、校园体育等全场景，实现了端侧实时部署与消费级落地。

## 二、运动场景AQA核心技术路线（2024-2026主流方案）
针对运动动作的时序性、发力关联性、场景多样性特点，当前运动领域AQA形成了5条成熟的技术路线，且呈现深度融合趋势：

### 1. 基于评分回归的AQA（竞技体育标配）
核心是端到端回归出与专业裁判对齐的连续分值，是跳水、体操等打分制竞技体育的主流方案。
- 最新突破：2025年提出的HP-MCoRe模型，通过层级姿态引导的多阶段对比回归，结合视觉-骨骼双模态特征，在FineDiving跳水数据集上SROCC达到0.982，刷新单模态模型性能上限；2026年最新的质量分数解耦模型，针对长体育视频分数分布不均的问题，通过Transformer解码器将特征解耦为高低质量子特征，在花样滑冰、艺术体操等长时序动作上，SROCC较基线提升8.3%。

### 2. 基于排序/对比学习的AQA（泛化性最优）
核心是学习“动作质量的相对差异”而非绝对分值，解决不同动作、不同个体的标准差异问题，尤其适合大众健身、校园体育等个性化场景。
- 最新突破：2024-2026年研究聚焦少样本对比学习，通过课程学习式的对比任务，实现少量标注样本下的模型微调，在击剑、射箭、攀岩等小众运动的零样本场景下，SROCC仍能达到0.85以上，解决了专业运动标注成本高的痛点。

### 3. 基于骨骼时空图卷积的AQA（细粒度评估核心）
运动动作的核心是关节的时空运动与协同发力，因此基于人体骨骼点的时空图卷积网络（ST-GCN及其变体）是运动AQA的技术底座。
- 最新突破：2025年研究引入生物力学先验，将关节力矩、发力顺序、肌肉激活约束融入图卷积邻接矩阵，实现从“表面姿态评估”到“深层发力质量评估”的突破，在健身、举重等对发力要求高的场景，错误识别准确率提升22%。

### 4. 多模态融合AQA（精度天花板）
2024-2026年研究热点，融合RGB视频、3D骨骼点、IMU可穿戴、肌电EMG、音频等多模态数据，解决单视觉视角受限、无法捕捉深层发力的问题。
- 最新突破：2024年NeurIPS发布的LucidAction数据集，配套多视角RGB、2D/3D骨骼点、动捕数据的多模态标注，基于该数据集的融合模型在8类体育运动上平均SROCC达到0.96；2025年ECCV的MultiModal-AQA模型，融合视觉与可穿戴传感数据，在乒乓球、健身动作上，评分精度较单视觉模型提升18%，同时实现了运动损伤风险的预评估。

### 5. 大语言模型驱动的可解释AQA（落地关键突破）
这是2024-2026年AQA领域最核心的突破，彻底解决了传统模型“黑盒打分、无法解释”的痛点，实现了“打分-错误定位-自然语言指导-训练方案生成”的全闭环，是AQA从实验室走向商业化的核心支撑。
- 最新突破：2025年IJCV提出的UIL-AQA模型，基于查询Transformer实现长视频片段级的可解释评分，在韵律体操、花样滑冰等长时序动作上，实现了每个动作片段的扣分点定位与原因解释，性能达到SOTA；2025年发布的LLM-FMS数据集与配套框架，将功能性动作筛查专业规则融入大模型，在健身动作上的纠错准确率达到92%，可直接替代初级健身教练的基础指导工作。

## 三、运动细分场景AQA研究与落地进展
运动场景是AQA技术最核心的应用载体，不同运动的评估难点、技术方案、落地进度差异显著，以下是2024-2026年各细分场景的最新进展：

### 1. 打分制竞技体育（跳水、体操、武术套路）
这是AQA研究最成熟、落地最早的场景，核心需求是对齐专业裁判标准、实现客观辅助评分与训练优化。
- **跳水**：AQA领域的标杆场景，最新的HP-MCoRe模型实现了起跳、空中姿态、入水水花的全流程细粒度评估，与FINA国际泳联裁判分的SROCC达到0.982，接近人类裁判的一致性水平；2025年研究进一步结合水下动捕数据，覆盖了入水后动作的评估，实现跳水评分全维度覆盖。
- **体操/花样滑冰**：2024-2026年核心突破是长时序成套动作评估，UIL-AQA模型解决了长视频时序依赖建模难题，实现艺术体操成套动作的片段级打分与扣分点定位，在FineGym数据集上SROCC达到0.95；针对花样滑冰快速移动、视角变化大的难点，2025年研究通过多视角3D重建，实现了旋转圈数、跳跃高度、落冰稳定性的精准评估，SROCC达到0.94，已用于多国国家队训练复盘。
- **武术套路**：国内研究处于全球领先地位，上海体育大学2025年发布的武术套路AQA系统，结合国家级裁判标准与大模型，实现了套路自动打分、架型纠错、发力顺序评估，已落地到全国武术锦标赛辅助裁判系统与中小学武术教学；2024年发布的Wushu-AQA数据集，填补了专业武术AQA标注的空白，支撑了传统武术的国际化推广。

### 2. 球类对抗运动（篮球、乒乓球、足球）
这是2024-2026年AQA研究的热点赛道，核心难点是“人-球交互”的联合评估，不仅要评估动作规范性，还要关联动作效果与战术合理性。
- **篮球**：2024年AAAI提出的人-球交互AQA模型，同时捕捉人体投篮动作与球的轨迹，实现了“动作质量+效果”的联合评估，解决了“蒙进的错误动作”与“没进的标准动作”的区分难题；清华团队2025年成果结合可穿戴传感器，实现了投篮发力顺序的精准评估，纠正“只用手臂发力”的核心错误，已落地到CBA青年队日常训练。
- **隔网对抗类（乒乓球/羽毛球/网球）**：2025年CVPR的多模态AQA模型，融合视觉挥拍动作、球的轨迹、击球音频、球拍IMU数据，实现了击球旋转、速度、落点，以及挥拍发力、步法到位率的细粒度评估，SROCC达到0.94；国内团队开发的乒乓球实时AQA纠错系统，已规模化落地到全国上千家乒乓球馆的AI训练设备。
- **足球**：2024年ECCV提出的群体-个体联合AQA模型，不仅评估球员个人射门、传球的动作质量，还结合场上战术场景评估传球时机、选择的合理性，实现“技术+战术”的综合评估，已被英超、德甲多家俱乐部用于青年队训练复盘。

### 3. 大众健身与康复运动
这是AQA商业化落地最广的场景，核心难点是个体差异大、视角多变、对可解释性要求高。
- **大众健身**：2024年ECCV发布的EgoExo-Fitness数据集，是全球首个同步第一/第三人称双视角、配套细粒度错误标注与专业指导的健身数据集，基于该数据集的模型在10类常见健身动作上，错误识别准确率达到93%；2025年研究通过域自适应对比学习，解决了不同身材、不同视角的泛化问题，实现了手机端30fps的实时纠错，目前Keep、FitTime等主流健身APP的AI教练均采用该技术路线。
- **康复运动**：2025年利物浦大学发布的UL-RED康复运动数据集，覆盖22种康复动作，配套多模态传感数据，基于该数据集的AQA模型，可精准评估康复动作完成度、监测患者康复进度，已落地到远程康复医疗场景；LLM-FMS框架结合功能性动作筛查标准，实现了运动损伤风险的预评估，已被多家运动康复机构采用。

### 4. 舞蹈与表现类运动
核心难点是除动作规范性外，还需兼顾节奏、力度、风格等主观维度的量化评估。
- 2024年ACM MM提出的时序对齐AQA模型，先将用户动作与标准动作做精准时序对齐，再评估每个节拍的关节角度、走位、力度与节奏匹配度，同时定位节奏与动作的双重错误；2025年研究进一步引入风格迁移模型，实现了舞蹈动作风格相似度的量化评估，解决了“动作到位但没有舞感”的评估难题，目前已落地到抖音、快手舞蹈跟拍评分与Steezy等专业舞蹈APP。

## 五、现存核心挑战与未来趋势
### 核心挑战
1.  **个性化评估能力不足**：当前模型大多采用统一标准，难以适配不同年龄、身材、运动基础人群的动作标准差异，尤其针对老年人、青少年、运动损伤人群的特殊需求适配不足。
2.  **主观艺术维度难以量化**：舞蹈、花样滑冰、武术套路等运动的风格、情感、精气神等主观艺术维度，仍难以实现精准、可解释的量化评估。
3.  **复杂场景泛化性有限**：消费级场景下，用户拍摄的角度、光线、遮挡情况复杂多变，模型在非标准视角下的性能会显著下降。
4.  **专业标注成本高**：AQA标注需要专业裁判、教练的参与，标注成本远高于动作识别，限制了数据集的规模与多样性。

### 未来发展趋势
1.  **通用运动AQA大模型**：构建覆盖全品类运动、适配不同人群、支持零样本评估的通用基座模型，实现“一个模型适配所有运动场景”。
2.  **3D数字孪生全维度评估**：通过单目摄像头实现人体动作的3D数字孪生，从3D空间全维度评估动作质量，彻底解决视角受限的核心痛点。
3.  **全周期健康管理延伸**：AQA从“动作质量评估”延伸到“损伤风险预评估-康复训练监测-运动能力提升”的全周期健康管理，成为大众运动健康的核心工具。
4.  **与具身智能深度融合**：AQA与AI陪练机器人、虚拟人教练结合，实现“实时评估-动态调整训练内容-陪练对抗”的全流程智能训练，替代初级教练的核心工作。
