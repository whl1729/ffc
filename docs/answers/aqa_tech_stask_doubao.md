# AQA（Action Quality Assessment 动作质量评估）循序渐进技术栈路线
先对齐你的背景：通信工程本科、10年工作、7年自动驾驶一线经验，优势是**车载感知、BEV、时序数据、工程落地、自动驾驶场景理解**；短板普遍集中在：视频时序建模、细粒度动作评估范式、数据集设计、学术评价指标、深度学习理论与实验方法论。
AQA 不是简单动作识别（Action Recognition）：
- 动作识别：**判断是什么动作**（分类）
- AQA：**评估同一个动作做得好不好、打分、定位缺陷时序区间**（回归+时序定位+细粒度对比）
自动驾驶场景下典型AQA任务：驾驶员操作质量评估、接管行为质量、行人/非机动车动作危险性评估、自动泊车轨迹动作质量、安全员操作合规性评估，和通用人体动作AQA（健身、手术动作）既有共通理论，又有场景差异。

整体路线分为4个阶段：**基础补课 → 计算机视觉与时序模型基础 → AQA专项核心理论与方法 → 自动驾驶场景AQA工程+科研闭环**

## 阶段1：前置基础（优先补齐，1～2个月）
> 你有自动驾驶感知基础，不需要从零学CV，重点查漏补缺
### 1.1 数学基础（抓重点，不用泛学）
- 线性代数：矩阵变换、特征值、投影（特征学习、注意力机制）
- 概率论与统计：极大似然、贝叶斯、分布、回归损失、置信区间
- 优化理论：梯度下降、正则化、损失函数特性
- 时序基础：马尔可夫链、时序信号特性（通信专业信号处理基础可以复用！）

### 1.2 Python & 深度学习工程底座（自动驾驶日常会接触，强化规范）
- Python进阶：面向对象、多进程、异步、NumPy/OpenCV
- PyTorch（优先，科研主流）；TensorFlow可选了解
- 工具链：
  - 数据处理：Pandas、PyAV（视频解码，AQA刚需）
  - 可视化：Matplotlib、TensorBoard、Wandb（实验记录，科研必备）
  - 标注工具：LabelMe、VGG Image Annotator、EVA（时序视频标注）

### 1.3 复用你通信专业优势：数字信号处理
视频本质是**时空域时序信号**，AQA核心就是时序信号质量打分：
时域滤波、时频分析、信号特征提取，非常容易迁移理解时序模型。

## 阶段2：计算机视觉 + 视频时序深度学习（核心地基，2～3个月）
> 先搞定视频理解通用框架，再切入AQA，不要直接跳论文
### 2.1 2D图像基础模型（感知通用，自动驾驶BEV/2D检测同源）
CNN基础：ResNet、ConvNeXt；预训练模型、特征提取、微调范式
目标检测：YOLO、DETR（AQA经常需要先检出人体/车辆主体，再提取动作特征）

### 2.2 视频时序建模【重中之重，AQA核心依赖】
#### 主流时序架构（按学习顺序）
1. **3D CNN**：C3D、R(2+1)D、SlowFast（工业落地最常用，自动驾驶视频基线）
2. **时序循环网络**：LSTM、GRU（入门理解时序依赖，现在少单独做主干）
3. **Video Transformer**
   - ViT → TimeSformer、VideoSwin Transformer（当前学术主流视频backbone）
   - 时空注意力机制：空间注意力（画面物体）+时序注意力（动作演变）

> 关键认知：AQA性能上限很大程度由**视频时序特征提取能力**决定

### 2.3 关键前置任务（AQA的上游）
1. Action Recognition 动作识别（分类）
2. Temporal Action Localization（TAL，时序动作检测：找到视频里动作起止时间）
3. Pose Estimation 人体关键点估计
   - OpenPose、MediaPipe、MMHuman3D
   ✅ **自动驾驶驾驶员AQA刚需**：基于人体骨架序列评估操作动作质量
> 两条AQA主流技术路线从此分化：
> 路线A：原始RGB视频时序建模（外观+动作）
> 路线B：基于骨架关键点时序序列建模（更轻量化、遮挡鲁棒，车载友好）

### 2.4 开源框架快速上手
必选：**MMVideo（OpenMMLab）**
内置SlowFast、TimeSformer、TAL、动作识别基线，可以快速跑通视频训练流程，直接作为后续AQA实验底座。

## 阶段3：AQA 专项核心知识（科研核心阶段，3～4个月，重点攻克）
### 3.1 先理清AQA标准任务定义
两类主流任务，自动驾驶都会用到：
1. **Scalar AQA（全局打分）**：给整段动作输出1个质量分数（0～1连续值，回归任务）
2. **Temporal AQA（时序细粒度评估）**：逐帧/片段输出质量分 + 定位动作哪里做得差（缺陷时序定位，更贴合自动驾驶落地需求）

### 3.2 AQA核心范式与经典方法（由浅入深学习）
#### 第一层基础范式：直接回归框架（Baseline，先复现）
视频/骨架特征编码器 → 时序聚合头 → MLP输出质量分数
损失函数：MSE、L1 Loss（基础回归损失）

#### 第二层：对比式AQA（当前主流思路，AQA区别于普通回归的精髓）
核心直觉：**动作好坏是相对的，优秀动作作为模板，计算相似度**
- Pairwise Comparison 成对比较学习（最经典！）
  输入两段同类型动作，模型判断哪一段质量更高，间接学到质量度量
- Ranking Loss / Ordinal Regression（序数回归）
  不再预测绝对分数，学习分数之间大小顺序，缓解标注主观偏差
> 痛点：自动驾驶驾驶员打分天然存在标注主观性，序数回归非常适合场景

#### 第三层：高级前沿方向（适合创新点挖掘，用于你的科研选题）
1. **时序注意力 + 关键片段挖掘**
   自动定位影响动作质量的关键时间段（例如驾驶员变道时观察后视镜这个关键动作）
2. **Graph-based AQA（骨架图卷积）**
   ST-GCN、2s-AGCN：把人体关键点构造成图，建模关节之间运动关系
3. **Prompt-based AQA / Video LLM辅助动作评估（前沿）**
   利用多模态大模型提供动作语义先验，适合开放场景AQA
4. **域自适应AQA**
   通用动作数据集预训练，迁移到自动驾驶驾驶员场景（解决自动驾驶AQA数据集稀缺痛点，**你的核心科研优势场景**）

### 3.3 AQA 数据集 & 评价指标（科研必备）
#### 通用公开数据集（先拿这些跑通模型，验证算法）
- 基于RGB视频：MTL-AQA、FineGym、UCF-QNRF-AQA
- 基于人体骨架：FIT3D
> 注意：通用健身/运动数据集和驾驶员动作分布差距大，只能做算法验证，最终需要构建自动驾驶私有数据集

#### 标准评价指标（论文必须汇报）
- SRCC（Spearman秩相关系数）【AQA第一核心指标！】
- PLCC（皮尔逊相关系数）
- MSE、MAE
简单理解：SRCC衡量模型预测分数顺序和人工标注顺序是否一致，AQA领域通用黄金指标。

### 3.4 论文阅读路线（循序渐进）
1. 综述先行：搜索 **Action Quality Assessment survey**，建立全局认知
2. 经典奠基论文：Pairwise AQA、Ordinal Regression for AQA
3. 骨干演进：SlowFast AQA、TimeSformer AQA、STGCN骨架AQA
4. 近三年顶会（CVPR/ECCV/ICCV）最新AQA工作，寻找创新缺口

## 阶段4：面向自动驾驶场景的AQA（你的差异化赛道，科研+工程结合）
> 绝大多数AQA研究聚焦健身、体操、手术动作；**自动驾驶驾驶员动作AQA属于细分蓝海，也是你7年行业经验最大护城河**

### 4.1 自动驾驶AQA特有输入模态（多模态融合是绝佳创新方向）
不止RGB摄像头视频，你可以融合：
1. 图像流：驾驶员舱内摄像头RGB、红外
2. 人体关键点时序序列
3. 车辆CAN总线信号：方向盘转角、油门刹车、车速、转向灯信号
4. 毫米波雷达、环视感知结果（周边交通参与者状态）

👉 **多模态时序融合AQA**：视觉动作 + 车辆动力学信号联合评估驾驶员操作质量，纯学术界很少做，非常契合你的背景。

### 4.2 自动驾驶场景特有挑战（直接转化为科研问题）
1. 遮挡：方向盘遮挡手部、光线变化、夜间红外
2. 动作差异大：不同驾驶员驾驶习惯差异，标注噪声大
3. 长尾：危险不良操作样本稀少
4. 实时性约束：模型需要轻量化适配车载边缘设备

对应可行科研切入点：
- 少样本/零样本AQA
- 模态缺失鲁棒AQA
- 轻量化时序模型、模型蒸馏部署
- 弱标注AQA（降低人工时序标注成本）

### 4.3 完整科研工程闭环（你落地必备）
1. 数据采集、时序标注规范设计
2. 数据集清洗、数据增强（视频时序增强：时间裁剪、帧率扰动、色彩扰动）
3. 基线复现、 ablation study（消融实验，论文必备）
4. 模型训练、指标对比、结果分析
5. 模型导出（ONNX/TensorRT）、车载部署验证
